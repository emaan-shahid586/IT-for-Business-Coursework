Overview: Assignment 1 required us to source a real-world business dataset for which I used Kaggle. Then I cleaned the raw data using TRIM, SUBSTITUTE and by using the correct formatting. e.g: using $ for currency. I also created samller reference tables using the LOOKUP function. SUM, SUMIFS AND COUNTIFS functions were used for calculations. I also used conditional formatting to spot outliers, trends and to read data fast. This was followed by creating pivot tables which were used to create visualisations which eventually made up the dashboard. I also included KPIs in the dashboard and concluded the assignment by drawing key insights and making business recommendations. 
Folder contents: This folder includes the excel assignment workbook, the professor's instructions pdf, a README and a dashboard preview image.
