Overview: In this assignment we were given a dataset of multiple tables and were asked to load it to power query and transform the tables (data cleaning, renaming columns, changing data types). After this we loaded the data to data model, created relationships between the tables using Power Pivot, labelled the tables as fact and dimension tables and restructured the tables to ensure the data model is correctly structured. We were also instructed to create 3 more tables, perform the same steps from data transformation to modeling on them and justify why we created those tables. The assignment was concluded by building a dashboard which used slicers and charts for visualization of the data.
Folder Contents: This folder includes the excel workbook which has the assignment, a word document which justifies the created tables, a README, a pdf of professor's instructions and a dashboard preview image.
